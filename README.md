# محفظتي — تطبيق إدارة المصاريف (PWA حقيقي)

تطبيق يعمل بالكامل من المتصفح، بياناته تتخزن **محلياً على جهازك فقط** (localStorage) — ما يمر على أي سيرفر خارجي، ويشتغل حتى بدون نت بعد أول فتحة.

## طريقة النشر على GitHub Pages (خطوة بخطوة)

1. سوّي مستودع (Repository) جديد في حسابك على GitHub، مثلاً بالاسم `mahfazti`.
2. ارفع كل ملفات هذا المجلد (`index.html`, `styles.css`, `app.js`, `manifest.json`, `sw.js`, ومجلد `icons`) إلى جذر المستودع مباشرة.
   - أسهل طريقة: من صفحة المستودع اضغط **Add file → Upload files** واسحب الملفات كلها.
3. روح لـ **Settings → Pages** في المستودع.
4. تحت **Source** اختر **Deploy from a branch**، وحدد الفرع `main` والمجلد `/root`، ثم احفظ.
5. انتظر دقيقة أو دقيقتين، بيطلع لك رابط شبيه بـ:
   `https://your-username.github.io/mahfazti/`
6. افتح هذا الرابط من متصفح جوالك (كروم أفضل خيار على أندرويد).
7. من قائمة المتصفح اختر **Add to Home Screen / تثبيت التطبيق** — بيتثبت فعلياً كتطبيق مستقل بأيقونته الخاصة، ويشتغل بدون شريط المتصفح.

## ملاحظات مهمة

- **البيانات محلية 100%**: كل مصروف وفئة ودين يتخزن بمتصفح جهازك فقط عبر `localStorage`. ما يوصل لأي سيرفر، حتى GitHub نفسه ما يشوفه.
- **النسخ الاحتياطي بين يدك**: استخدم زر "تصدير CSV" داخل التطبيق بشكل دوري واحفظ الملف بمكان تثق فيه (جوجل درايف مثلاً) — لأن مسح بيانات المتصفح أو تغيير الجهاز يفقدك البيانات المحلية.
- إذا سويت تعديل على أي ملف بعدين، لازم ترفعه GitHub من جديد عشان التغيير ينعكس على الرابط المنشور.
- التطبيق يدعم العمل بدون إنترنت بعد أول زيارة بفضل Service Worker المُضمّن (`sw.js`).
